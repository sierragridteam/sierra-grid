# The region, in three tenses

The primary discovery action is choosing a tense: **Now / Ahead / Recorded**. Each changes the kind of evidence that can answer a question. Current weather and conditions occupy Now; NWS hourly periods and scheduled events occupy Ahead; bounded event revisions and device measurements occupy Recorded. A persistent subject index crosses those temporal lenses, so mesh is one subject among many.

The opening Now view assembles live weather and a scoped regional summary. Ahead exposes the shape of a forecast and planned road windows. Recorded offers explicitly bounded revision exploration; it never pretends that conditions, cameras, source health or forecast vintages have archives. Each row is a doorway into a contextual evidence sheet, original source text, measurement units, clocks, provenance, and full structured fields.

The visual grammar is a printed temporal atlas: warm paper, forest ink, large serif tense labels, fine rules, numbered entries and a three-position time rail. Shared DS typography, logos, controls and chart rendering carry the evidence. URL state preserves tense, subject, place and detail selection.

## Concept checkpoint

Three options were proposed independently: a question-led editorial Fieldbook; an Evidence Loom combining two simultaneous strands without implying causation; and Region in Three Tenses. The coordinator selected Three Tenses before data UI implementation. The preliminary static shell was adapted to temporal navigation. No competing implementation was inspected.
